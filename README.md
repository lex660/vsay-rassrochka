# Сравни рассрочку

Агрегатор предложений исламской рассрочки (мурабаха) по России: калькулятор,
сравнение условий компаний и ссылки на первоисточники.

**Сайт:** https://lex660.github.io/vsay-rassrochka/

## Как устроено

Статический сайт на Eleventy. Бэкенда нет: расчёт идёт в браузере по
`data/tariffs.json`, поэтому сайт работает, даже когда сайты компаний недоступны.
Ставок в коде нет — все числа лежат в данных, с указанием источника и даты проверки.

| Путь | Что там |
|---|---|
| `data/tariffs.json` | Компании и тарифы. Единственный источник истины |
| `src/assets/js/calc.js` | Формулы расчёта. Работает и в браузере, и в тестах |
| `src/assets/js/app.js` | Интерфейс калькулятора |
| `src/*.njk` | Страницы: главная, регионы, компании, о проекте, реклама, политика |
| `tests/` | Тесты расчёта на эталонных примерах и тесты сверки |
| `scripts/check-site.mjs` | Проверка перед релизом: ссылки, CSP, дисклеймер, согласие, sitemap |
| `functions/reconcile/` | Ежедневная сверка тарифов с сайтами компаний |
| `docs/` | Аудит, исследование рынка, план, решения (ADR), состояние работ |

## Локальный запуск

```sh
npm install
npm start          # http://localhost:8080
```

## Проверки

```sh
npm run lint       # ESLint
npm test           # тесты расчёта и сверки
npm run build      # сборка в _site
npm run check      # проверка собранного сайта
```

Те же проверки прогоняет CI на каждый pull request (`.github/workflows/ci.yml`)
и перед публикацией (`.github/workflows/deploy.yml`).

## Публикация

Пуш в `main` запускает сборку и публикацию. Адрес сайта задаётся переменной
репозитория `SITE_URL`; без неё используется адрес GitHub Pages.

Основной вариант хостинга — Yandex Object Storage: он включается автоматически,
как только в репозитории заданы переменная `YC_BUCKET` и секреты
`YC_ACCESS_KEY_ID`, `YC_SECRET_ACCESS_KEY`. Пока их нет, сайт публикуется
на GitHub Pages. Пошаговая инструкция — `РУКОВОДСТВО.md`.

## Терминология

Проект пользуется шариатской терминологией: **наценка**, а не процент.
Условия на сайте — справочные, это не оферта и не финансовая консультация.
